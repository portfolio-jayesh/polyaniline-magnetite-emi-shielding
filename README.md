# Polyaniline–magnetite composites for EMI shielding

Jayesh Jadhav · Materials research project

The project investigated a polyaniline/Fe₃O₄ composite for electromagnetic interference shielding. Characterization included electron microscopy, X-ray diffraction, infrared spectroscopy and vector network analyzer measurements.
